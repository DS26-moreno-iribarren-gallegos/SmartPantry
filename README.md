# SmartPantry

Repositorio del Trabajo Práctico Integrador de Desarrollo de Software 2026.

## Pre-requisitos

* [.NET10.0+ SDK](https://dotnet.microsoft.com/download/dotnet)
* [Node v18 or 20](https://nodejs.org/en)

### Antes de ejecutar la aplicación

* Ejecutar el comando `abp install-libs` en la carpeta de la solución para instalar las dependencias de paquetes del lado del cliente. Este paso se realiza automáticamente al crear una nueva solución, a menos que lo hayas desactivado explícitamente. Sin embargo, debes ejecutarlo manualmente si has clonado la solución desde el control de versiones o si has añadido una nueva dependencia de paquete del lado del cliente a la solución.

* Ejecutar `SmartPantry1.DbMigrator` para crear la base de datos inicial. Este paso también se realiza automáticamente al crear una nueva solución, salvo que lo hayas desactivado explícitamente. Es necesario hacerlo en la primera ejecución, así como cuando se añada posteriormente una nueva migración de base de datos a la solución.
